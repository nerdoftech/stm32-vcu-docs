    Parameters¶

    Generated

    Generated by scripts/gen_param_reference.py from include/param_prj.h of firmware 2.41A (commit b061f84). Edit descriptions in scripts/param_descriptions.py, not here.

    Parameters are settings you change in the web interface or with the terminal set command and store with save. Values are checked against min/max when set through the terminal, web UI or CAN SDO. The ID is the stable number used to store the value in flash and to address it over CAN SDO (index 0x21hh, sub-index ll for ID 0xhhll; see CAN mapping).
