    Spot values¶

    Generated

    Generated by scripts/gen_param_reference.py from include/param_prj.h of firmware 2.41A (commit b061f84). Edit descriptions in scripts/param_descriptions.py, not here.

    Spot values are read-only values the firmware computes and publishes (the web interface plots them). They are not saved. You can read them with the terminal get command, stream them with stream, or send them on CAN with a CAN map tx entry.
